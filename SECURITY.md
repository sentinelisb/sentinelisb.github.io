# Security Policy

Sentinel Intelligence & Security Bureau takes the security of its website
seriously. Thank you for helping us keep it safe.

## Supported Versions

The website is updated continuously, so only the latest published version is
supported with security fixes.

| Project                                  | Supported           |
| ---------------------------------------- | ------------------- |
| Website (https://sentinelisb.github.io/) | Latest version only |
| Older copies or saved versions           | Not supported       |

## Reporting a Vulnerability

Please report security problems privately. Do not post them in public issues,
social media or messages.

- **Email:** sentinel.isb@gmail.com with the subject "Security report"
- **Phone/WhatsApp:** +91 84280 17092, for urgent matters

Please include:
- What you found and where (page or feature)
- Steps to reproduce it
- What could happen as a result
- Screenshots if they help, with no real personal data in them

### What to expect

- We will acknowledge your report within **3 working days**.
- We will send an update at least every **7 days** until it is resolved.
- If we accept the report, we will fix it and tell you when it is done.
- If we decline it, we will explain why.
- Please give us reasonable time to fix the issue before sharing it publicly.

### Scope

In scope: the website at the address above.

Out of scope: spam, denial-of-service testing, social engineering or phishing
of our people, physical attacks, and problems in third-party services such as
GitHub, WhatsApp or Google.

### Good-faith testing

Please test only with your own data and accounts. Do not access, change or
download anyone else's information, and stop and tell us straight away if you
come across personal data. We will not take action against people who follow
this policy and act in good faith.
